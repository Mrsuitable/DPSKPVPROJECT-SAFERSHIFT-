# SaferShift Benchmark Reports

## Contents
This directory contains comparative evaluation results addressing the core research question:
**"Can personalized calibration reduce false alarms while preserving the detection of genuine fatigue indicators?"**

- `benchmark_report.md`: Markdown summary of event-level precision, recall, F1, false alarms per minute, detection delay, and robustness checks.
- `benchmark_report.json`: Machine-readable results and confusion matrices for both Standard Mode and Personalized Mode.
